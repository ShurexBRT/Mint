# MINT — Autonomous Micro-Business Engine

MINT is a zero-cost-first, local-first system for discovering, challenging, and validating micro-business opportunities.

## Current phase

Phase 1 focuses on proving the decision pipeline:

`Scout → Analyst → Scorer → Palermo → Director`

The system must prefer **no recommendation** over fabricated demand.

### Hard rule

**External spend limit: €0.**

MINT must never spend money autonomously. Paid APIs, ads, subscriptions, trading, gambling, paid hosting, paid data, or any other action that can create a charge are prohibited.

## First milestone

Identify one real market problem worth validating.

The later economic milestone is the first **€1 of verified external revenue**.

## Stack

- Node.js + TypeScript
- SQLite + Drizzle ORM
- Zod
- Express REST API
- React + Vite dashboard
- Vitest

Everything in Phase 1 runs locally and offline. No API key is required.
